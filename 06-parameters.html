7. Parameters

← 06 Code Implementation | Next: 07 Experiments

7.1 Parameter groups

  • Numerical — Δt, T_\max, Nx​,Ny​, Nb​. Here Nb​ is the number of lagrangian point on the boundary.
  • Fluid — ν: physical (blood).
  • Geometry — Lx​,Ly​,D0​: physical scale of a small cerebral artery.
  • Wall mechanics — Kwall,x​,Kwall,y​,Kmem​: numerical stiffnesses, first obtained by mapping a stable earlier configuration (7.3 March → physical mapping) and then set by the parameter study (07 Experiments > 8.2 Stable parameter range for K_mem, K_tar and σ_p0); not yet derived from wall modulus/thickness.
  • Myogenic — σp0​,kp​,r0​.
  • Drive — G, g(t) (T, a): chosen for a target peak speed and a heart-rate-like period.
