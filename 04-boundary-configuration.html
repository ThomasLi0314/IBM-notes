4. Boundary Configuration

← 03 Problem Setup | Next: 05 Forces

4.1 Wall discretization

  • Two walls (top, bottom), each an open chain of Nb​=512 Lagrangian points spanning the full domain length (200 before 2026-10-14).
  • Initial positions:
Xktop​=(xk​, 2Ly​​+2D0​​),Xkbot​=(xk​, 2Ly​​−2D0​​),xk​=Nb​−1kLx​​, k=0,…,Nb​−1
  • Nodes k=0 and k=Nb​−1 sit at x=0 and x=Lx​, which coincide under periodicity.

4.2 Ghost / target points

The ghost point is a special modification in Immersed boundary method to represent a restoring force that drag the drifted boundary point to it’s initial condition. In order to simulate a solid.

  • Ytop=Xtop(t=0), Ybot=Xbot(t=0), fixed in time.
  • Every wall point is tethered to its own target point (see 05 Forces > 5.1 Tether (penalty) force).

4.3 Tether stiffness (uniform, anisotropic)

Every wall node is tied to its own target point with separate stiffnesses along the wall (x) and across it (y). Both stiffnesses are the same at every node (no extra anchoring at the ends):

Fk,xtet​=Kx​(Yk,x​−Xk,x​),Fk,ytet​=Ky​(Yk,y​−Xk,y​)
DirectionCode variableValue (µm/s²)Role
x (axial, along the wall)K_wall_x2.34×109 ("Ktar​" in 07 Experiments)strong: holds the wall against the mean wall shear, so it does not drift downstream
y (radial, across the wall)K_wall_y9.36×105weak: the radial position is left to the fluid pressure, the springs and the myogenic stress
  • The axial tether is uniform so that the shear moves every node by the same amount: the wall shifts as a whole instead of being compressed against fixed ends.
  • The radial tether is uniform because the periodic domain stands for an infinitely long vessel, which must dilate uniformly. Stiff radial anchoring at the ends created a “pinch” that tore the wall once the lumen was pressurized (2026-10-13).
  • The code still contains an older exponential end-anchoring formula (tether_profile, K_tar, decay_len), but with the current values it has no effect in main.m: the axial profile is clipped to K_wall_x everywhere (K_tar_vec_x = 2.34e9 at all nodes), and the radial profile is set to K_wall_y directly.

Why anisotropic. With the former isotropic floor Kwall​=9.36×106 in both directions:

  1. the mean wall shear dragged the wall interior ≈ 37 µm downstream while the ends stayed fixed, putting the downstream half under ≈ 9 % compression; the spring chain (no bending stiffness) then collapsed locally after ≈ 22 s (a=0.2) or ≈ 8 s (a=0.6) — see 08a Earlier Experiments > A.8 Long-run compressive collapse (isotropic tether);
  2. the same radial tether pulled any outward bulge back, so the radial balance was set by the tether rather than by pressure vs. myogenic stress.

Physically, the axial anchoring stands for the perivascular tissue that holds a vessel in place lengthwise, while the radial direction must stay free for dilation/constriction.

Experiment scripts

The older experiment_*.m scripts still use the legacy isotropic, exponentially decaying profile K_tar_vec (ends K_tar = 2.34e8, interior K_wall = 9.36e6) in their own copy of the time loop. main.m does not use it.

4.4 Node pairing for the myogenic force

  • Top node k is paired with bottom node k (same index, same initial x).
  • Local “diameter” rk​=∣yktop​−ykbot​∣. Valid while the walls stay roughly horizontal and do not slide relative to each other.
